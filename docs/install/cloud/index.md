# Cloud Platforms

We provide install guides and example templates for deploying Neural Inverse Cloud to your
cloud of choice.

<div class="tabs">

## AWS

We publish Neural Inverse Cloud Community Edition on the AWS Marketplace. Follow the tutorial here:

- [Install Neural Inverse Cloud Community Edition from AWS Marketplace](./aws-marketplace.md)

Alternatively, install the [CLI binary](../cli.md) on any Linux machine or
follow our [Kubernetes](../kubernetes.md) documentation to install Neural Inverse Cloud on an
existing Kubernetes cluster.

For EKS-specific installation guidance, see the [AWS section in Kubernetes installation docs](../kubernetes.md#aws).

## GCP

We publish a GCP Marketplace listing with Neural Inverse Cloud pre-installed. Follow the
tutorial here:

- [Install Neural Inverse Cloud on GCP Compute Engine](./compute-engine.md)

Alternatively, install the [CLI binary](../cli.md) on any Linux machine or
follow our [Kubernetes](../kubernetes.md) documentation to install Neural Inverse Cloud on an
existing GKE cluster.

## Azure

Use the following guide to run Neural Inverse Cloud on an Azure VM:

- [Install Neural Inverse Cloud on an Azure VM](./azure-vm.md)

Alternatively, install the [CLI binary](../cli.md) on any Linux machine or
follow our [Kubernetes](../kubernetes.md) documentation to install Neural Inverse Cloud on an
existing GKE cluster.

## Other

Is your cloud missing? Check [unofficial](../other/index.md) install methods or
install the [standalone binary](../cli.md).

</div>
